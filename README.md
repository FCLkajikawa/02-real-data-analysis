都の気象データ分析
概要

Open-Meteo APIから2025年の京都の気象データを取得し、Pythonを使ってデータ分析を行った。

気温・降水量・風速などのデータを前処理・集計し、月ごとの変化や各項目の関係を分析した。

使用技術
Python
Pandas
Matplotlib
Requests
Open-Meteo API
Jupyter Notebook
使用データ

Open-Meteo APIから2025年1月1日〜12月31日の京都の気象データを取得。

使用した主な項目：

date：日付
temperature：平均気温
precipitation：降水量
wind_speed：最大風速
month：月
分析内容
1. データ取得

Open-Meteo APIをRequestsで呼び出し、JSON形式の気象データを取得した。

2. データ前処理
JSONデータをDataFrameへ変換
カラム名を整理
日付をdatetime型へ変換
欠損値を確認
重複データを確認
月の情報を追加
3. 月別集計

月ごとに以下の指標を計算した。

平均気温
平均降水量
最大風速
4. 可視化

Matplotlibを使用して、以下のグラフを作成した。

月別平均気温
月別平均降水量
月別最大風速
気温と降水量の関係
5. 相関分析

月別の平均気温と平均降水量の相関係数を計算した。

2025年の京都の月別データでは、相関係数は約0.71となり、正の相関が見られた。

ただし、相関関係だけでは因果関係を判断できないため、より長期間のデータや他の気象要因を含めた分析が必要である。

分析結果
月平均気温は8月が最も高く、約29.28℃だった。
月平均気温は2月が最も低く、約2.79℃だった。
月平均降水量は6月が最も高く、約9.47 mm/日だった。
月間最大風速は2月が最も高く、25.3だった。
気温は春から夏にかけて上昇し、8月をピークに秋から冬にかけて低下する傾向が見られた。
